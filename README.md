## Overview

DUNE 3 is a virtual analog synthesizer famous for its enormous supersaw engine, capable of stacking up to 8 detuned oscillators per voice with a dual filter, arpeggiator, and a 4-part multitimbral engine.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Synapse DUNE** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Supersaw Engine** | Up to 8 detuned oscillators per voice for enormous unison pads |
| **Dual Filter** | Parallel and series filter routing with 12 filter types |
| **4-Part Multitimbral** | Run four independent patches simultaneously in the engine |
| **Arp and Chord** | Built-in arpeggiator with chord memory and step-latch mode |
